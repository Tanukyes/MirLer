# Настройка Яндекс.Диска для фотовитрины

## Что нужно сделать один раз

### 1. Получить OAuth-токен Яндекс.Диска

Есть два способа:

#### Способ А — Быстрый (тестовый токен, живёт 1 год)

1. Перейдите по ссылке:
   https://oauth.yandex.ru/authorize?response_type=token&client_id=d4f8e5b8a68f4fb8b2e5cbcfaa3e9d5a
   
   > Это стандартный клиент Яндекс.Диска для WebDAV/API.

2. Авторизуйтесь под аккаунтом, на чей диск будут загружаться фото.

3. Скопируйте `access_token` из URL (после `#access_token=`).

#### Способ Б — Надёжный (своё приложение, долгоживущий токен)

1. Откройте https://oauth.yandex.ru/ и создайте приложение:
   - Платформа: **Веб-сервисы**
   - Redirect URI: `https://oauth.yandex.ru/verification_code`
   - Доступ: **cloud_api:disk.write** + **cloud_api:disk.read**

2. Скопируйте **Client ID** своего приложения.

3. Откройте в браузере:
   ```
   https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID
   ```

4. После авторизации скопируйте токен из адресной строки.

---

### 2. Прописать токен в .env

Откройте файл `.env` в корне проекта и замените заглушку:

```
VITE_YANDEX_DISK_TOKEN=y0_AgAAAA...ваш_токен...
VITE_YANDEX_DISK_FOLDER=wedding-photos
```

`VITE_YANDEX_DISK_FOLDER` — имя папки на диске. Папка создаётся автоматически при первой загрузке фото.

---

### 3. Пересобрать проект

```bash
npm run build
```

---

## Как это работает

```
Гость делает фото (камера браузера)
         ↓
  Браузер → Яндекс.Диск API
  (загрузка через OAuth-токен)
         ↓
   Папка wedding-photos на диске
         ↓
  Сайт периодически запрашивает список файлов
  из этой папки и показывает витрину
```

## Важные замечания

- **Токен видят все посетители сайта** (он попадает в JS-бандл через `import.meta.env`).  
  Это нормально для приватного свадебного сайта, но **не подходит для публичных проектов**.  
  Если хотите скрыть токен — сделайте небольшой бэкенд (Vercel Functions, Netlify Functions)
  который принимает загрузку и сам обращается к Яндекс.Диску.

- Фото публикуются автоматически (становятся доступны по прямой ссылке) сразу после загрузки.

- Витрина обновляется каждые 30 секунд.

- Превью-изображения (thumbnails) в сетке берутся через API Яндекса и требуют того же OAuth-токена.
  Если превью не грузятся — Яндекс мог ограничить доступ; полноразмерные фото откроются в лайтбоксе.
